# Smart Voice Study Clock ⏰🎙️

A personalized desktop study schedule and voice reminder application built with Python (`tkinter` and `pyttsx3`). I created this project to organize my daily study sessions and receive automatic audio alerts without constantly checking the clock.

## ✨ Features
- **Custom Study Routine:** Add multiple subjects with specific start and end times (24-hour format).
- **Live Digital Clock & Countdown:** Real-time clock display alongside a live countdown for the active study subject.
- **Automated Voice Reminders:** Plays an alarm beep and announces when a subject starts, when 1 hour or 30 minutes remain, and when it transitions to the next subject.
- **Clean UI:** Designed with a soothing powder-purple interface using Python's `tkinter`.

## 🛠️ Technologies Used
- **Python 3**
- **Tkinter** (GUI Design)
- **pyttsx3** (Offline Text-to-Speech Engine)
- **winsound & datetime**

## 🚀 How to Run
1. Install the required voice library:
   ```bash
   pip install pyttsx3
   ```
2. Run the application:
   ```bash
   python Study-Clock.py
   ```
